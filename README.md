# Tram Surfer

An endless runner in the spirit of Subway Surfers, set on Melbourne's tram
lines. A kid is running for his life across the tops of Melbourne trams, and a
wild dingo is right behind him.

**Play:** open `index.html` from any static web server (see below). It is built
to be hosted on GitHub Pages, e.g. at `https://hexagonal.zone/tram-surfer/`.

## Status

An endless run with three tram lanes through five stretches of a stylised
Melbourne, which change over seamlessly mid-run.

- Jump, roll and switch lanes; run up boarding ramps onto parked trams and
  hop along and across their roofs (no pantographs, so the roofs are clear)
- W class (green and City Circle maroon), Z class in 1975 mustard, E class and
  G class trams, parked or coming down the line at you (listen for the bell)
- Roadworks barriers to jump over or roll under, coins, a score multiplier
  that grows with distance, and a best score saved in the browser
- Pup, the chibi dingo: bump the side of a tram and you stumble, which slows
  you down and brings him right up behind you, where he stays in view as a
  warning. Stumble again within 20 seconds and he chomps you; after 20 clean
  seconds he drops back and a stumble only slows you again. Run into a tram or
  a barrier head-on and it's game over
- Five levels: every run starts on Swanston St, then the others follow in
  random order, and a level can't come back until two others have been seen:
  - **Swanston St**: sakura, lanterns and the State Library
  - **Bourke St**: golden tiles for a road surface, Parliament House at the end
  - **St Kilda Rd**: lined with plane trees, the Arts Centre spire ahead
  - **Collins St**: at night, with neon, lit windows and glowing trams
  - **Yarra**: a brown river; the kid surfs on a board, ferries replace the
    trams, floating crates replace the barriers, and footbridges are there to
    roll under. Ride a gangplank up onto a ferry roof
  - Street levels last about 80 seconds; the Yarra about 20–25 seconds
    (never more than 30)
- Intro animation (SURFER, DINGO, chomp chomp), start screen with the story,
  pause menu and game over screen
- Procedural lofi music (`music/lofi.js`), new music each run, muffled when
  paused or caught, plus synthesised sound effects
- Sound control: speaker button (mute) and volume in the pause menu

## Controls

| Action | Keyboard | Touch |
| --- | --- | --- |
| Change lane | ← → or A D | swipe left / right |
| Jump | ↑, W or Space | swipe up |
| Roll (or drop fast from a jump) | ↓ or S | swipe down |
| Pause | P or Esc | ❚❚ button |
| Mute | M | speaker button |
| Volume | − / + | pause menu |

## How it's built

Plain JavaScript modules and a 2D canvas, no build step and no dependencies.
The game draws into a 640×360 buffer with a small Doom-style software renderer
(a port of the concept-art renderer in `concept/`): exact scan conversion of
floors, side walls and camera-facing walls, billboard sprites, a z-buffer,
distance fog and cel outlines. Each frame is then snapped to a fixed
64-colour palette (no dither) and scaled up with nearest-neighbour.
WebAssembly wasn't needed.

The menus, HUD and pixel font are laid out on a 320×180 grid and drawn in 2×2
blocks, so they keep their chunky look. The 3D view uses the full 640×360.
If a machine can't keep up (frames averaging over 15 ms), the 3D view drops to
320×180 for the rest of the session.

| Path | What |
| --- | --- |
| `index.html` | the page; scales the 640×360 screen to fit |
| `src/main.js` | main loop, input, screen flow |
| `src/game.js` | the run: physics, collisions, the dingo, level generator |
| `src/render.js` | the software renderer |
| `src/trams.js` | tram and ferry classes, liveries and textures (with night lighting) |
| `src/zones.js` | the five levels: road surfaces, skies, fog, shopfronts, landmarks, level order and lengths |
| `src/street.js` | the street around the run: road or river, shopfronts, verandahs, trees, signs, landmarks |
| `src/sprites.js`, `src/characters.js` | the kid, Pup, coins, lanterns, trees |
| `src/screens.js` | HUD, intro, start, pause and game over screens |
| `src/audio.js` | shared AudioContext, music, sound effects, volume |
| `src/gfx.js` | framebuffer, palette snapping, pixel font, Japanese text |
| `src/palette.js`, `src/jptext.js` | generated by `tools/gen_assets.py` |
| `music/` | the lofi music engine and its playground |
| `concept/` | concept art and the Python renderer that made it |

Japanese text is decorative; it is pre-rendered from the Unifont JP and
WenQuanYi Zen Hei Sharp pixel fonts by `tools/gen_assets.py`, so the game
needs no web fonts.

## Running locally

ES modules don't load from `file://`, so serve the folder:

```sh
python3 -m http.server
# then open http://localhost:8000/
```

To test a level, start the run in it with `?zone=`, e.g.
`http://localhost:8000/?zone=yarra` (`swanston`, `bourke`, `stkilda`,
`collins` or `yarra`). Add `&res=high` or `&res=low` to fix the 3D view at
640×360 or 320×180 instead of choosing it automatically.

If you change the palette or the Japanese text in `tools/gen_assets.py`,
rerun it to regenerate `src/palette.js` and `src/jptext.js`.

## Hosting on GitHub Pages

The repo root is the site. In the repository's Settings → Pages, set the
source to "Deploy from a branch", branch `main`, folder `/ (root)`. With
`hexagonal.zone` set up as the user site's custom domain, the game appears at
`https://hexagonal.zone/tram-surfer/`. All paths are relative, so it works
under any sub-path.
