# Tram Surfer

An endless runner in the spirit of Subway Surfers, set on city tram lines. Dodge oncoming trams, hop between tracks, slide under overhead wires and grab coins as the speed keeps climbing.

## Status

Early days: nothing playable yet. The engine and tech stack are still to be decided.

## Planned gameplay

- Three tram lanes: swipe or use the arrow keys to switch lanes
- Jump over barriers and slide under obstacles
- Collect coins and power-ups along the way
- Speed increases the longer you survive
