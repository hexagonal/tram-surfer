music.newGame(nextSeed);   // new run, new music
music.setTempoScale(1.15); // runner speeding up
music.setMuffle(0.8);      // paused
music.on('note', n => ...); // sync visuals to the beat

    Everything is synthesised with Web Audio: FM electric piano, sub bass, drum machine, vinyl crackle and tape wobble. A tram bell rings at the start of every track.
